Introducing BatOS. My very own web based OS.
The theme is Batman inspired.
There are drag-able windows, open and close buttons. The bat icon on the welcome screen is a "close" button.
Two apps one is a simple app. Second is an app that opens another window inside the BatOS to show my other app (that responds to your hand movements)
The top menu bar has live time and a special surprise button.
The app icons are custom I made the first one myself, second one is a ss of the app preview 😁
AI is used in understanding js and some Css fixing and optimizing. 
You can clone the repo and open index.html to see the BatOS or directly go to bat-os-gocel.vercel.app
