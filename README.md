🦇 BatOS - Web-Based Desktop Environment
BatOS is a lightweight, browser-based operating system user interface built entirely with vanilla web technologies. Batman-themed desktop environment.

It features functional desktop mechanics including draggable windows, clickable app icons, and a live top menu bar.

✨ Features
Interactive Desktop Icons: Single-click to highlight an app, double-click to launch the application window.

Draggable Windows: Fully functional drag-and-drop mechanics allowing users to reposition open windows anywhere on the screen.

Live System Clock: A real-time JavaScript clock integrated into the frosted-glass top navigation bar.

Gotham Aesthetic: A sleek, dark UI featuring frosted glass effects (backdrop-filter), custom Batman branding, and classic dark gray and yellow color palettes.

🤖 The Role of AI in Development
Artificial Intelligence was utilized as a pair-programming assistant during the development of this project. Its primary roles included:

Debugging & Troubleshooting: Diagnosing layout breaks (like CSS Flexbox stacking issues) and fixing scrollbar clipping bugs caused by default browser margins.

UI/UX Refinement: Recommending specific CSS properties (like text-decoration: none, border-radius, and rgba color values) to upgrade the visual aesthetic from a standard layout to a polished Batman theme.

Mentorship: Explaining why certain code changes were necessary (e.g., explaining how Flexbox rows interact with display: block vs. display: flex for window containers) without writing the core logic from scratch.

🚀 How to Use
Since BatOS is built with static web files, running it locally is incredibly simple. You do not need a local server or Node.js to test it.

Clone the repository:

Bash
git clone https://github.com/thedev-k/WebOS.git
Navigate to the project directory:

Bash
cd WebOS
Run the OS:
Double-click the index.html file to open it in your default web browser (Chrome, Firefox, Safari, etc.).

🛠️ Usage Instructions (Inside BatOS)
To open an app: Double-click the "APP" icon on the left side of the desktop.

To move a window: Click and hold the header of the open window, then drag your mouse to move it around the screen.

To close a window: Click the Batman logo inside the opened window.

Surprise: Click the yellow button in the top navigation bar.
